HGFloater

Your windows, your programs and your controls in one small box

A clock floats wherever you park it, on any monitor or on the taskbar. Click it, or press Win + Alt + Space, and it opens into a grid with one icon per open window, one per shortcut you keep, and buttons for sound, screens, notes and the clipboard. Every icon has a key, so the fourth window is always Shift + 3.

  • Windows 11, 64-bit
  • One .exe, under 1 MB
  • No installer, no service
  • Never reaches the network
  • MIT open source

What HGFloater does well

One icon per window, one key per icon

A program with four windows gets four icons. Windows take Shift + 0 to 9 and shortcuts take Shift + A to Z, so the keys do not move when windows come and go. Pointing at an icon outlines its window on the desktop, and browser, Explorer and Terminal tabs can be icons of their own.

The taskbox

The folder is the setting

Drop a .lnk into the shortcuts folder and its icon appears within a second; rename it to change the order. Shortcuts to folders go to a Dir list of their own instead of crowding the grid.

Shortcuts on the grid

Volume, brightness and opacity at a glance

Vol, Mon and Alp show their value as a gauge and change with the wheel. The A/V Control Center switches the audio device, the Win + P arrangement, scaling, resolution and the real monitor brightness over DDC/CI or a laptop's backlight.

The A/V Control Center

Notes and a clipboard history

Notes are plain .txt files you can open anywhere, with search, archive and drag-to-reorder. The clipboard history keeps text in memory only and never writes it to disk.

Notes

A command box for windows

go 1 focuses a window, move 1 100 100 2 puts it on display 2, find windows word searches titles. The same box opens notes, takes clips and changes any setting or key.

The command box

Nothing behind your back

No installer, no service, no logs, no network. Settings are one plain config.ini, notes are text files beside it, and the only registry value is the optional Start with Windows entry.

What is tested

  • Every release is built warning-clean and checked automatically on a Windows 11 virtual machine before it is published.
  • That machine has one virtual monitor and no real backlight, so two things have not been verified yet: brightness of physical monitors over DDC/CI, and use with two or more monitors.
  • Two features are off in published builds until the executable is code-signed: the maximize-button menu and Start with Windows.
